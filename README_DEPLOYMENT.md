# Influencers Involved — Preliminary Website

This is a lightweight, multi-page static website prepared for the initial public presence of Influencers Involved, Inc. NFP.

## Included pages
- Home
- Mission
- 1% Influence Challenge
- About
- Transparency
- Contact
- Privacy

## Important content decisions
- Describes the organization as pre-launch.
- Uses the current direct-to-charity Phase 1 model.
- Does not claim participants, donations, partnerships, or impact that do not yet exist.
- Does not solicit donations or collect pledge/proof data.
- Does not publish an EIN, personal phone number, private address, or private board details.

## Fastest deployment route
1. Create a new public GitHub repository named `influencers-involved-site`.
2. Upload the contents of this folder to the repository root.
3. In repository Settings > Pages, deploy from the `main` branch and `/ (root)`.
4. Add `influencersinvolved.org` as the custom domain.
5. In Squarespace DNS, add the records GitHub provides and wait for HTTPS to activate.
6. Test every page, link, email address, and mobile layout before submitting the domain to Google.

## Alternative route
Recreate the same content in Google Sites or Squarespace. The HTML files can be used as the approved copy source.

## Before publishing
- Confirm inbound mail works for `ho@influencersinvolved.org`.
- Confirm the exact legal name and federal-status wording.
- Review leadership names and titles.
- Review the privacy notice.
- Do not add a donation button until banking, charitable-registration, and payment-processing requirements are ready.
